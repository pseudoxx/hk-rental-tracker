香港租盤追蹤器
HK Rental Tracker

一個本地運行的香港租務市場分析工具及 Codex Skill，用於按區域或屋苑追蹤租盤、租金、實用面積、呎租、來源狀態及每日市場變化。

這是什麼

香港租盤追蹤器面向需要觀察香港租務市場的人，支援本地任務配置、SQLite 數據庫、來源適配器、去重、每日掃描、摘要生成及日終報告導出。

目前預設來源包括美聯物業、中原地產、香港置業及利嘉閣。工具會記錄租盤首次出現時間、來源下架信號、租金變化、實用面積、呎租、樓層室號與跨平台狀態。
